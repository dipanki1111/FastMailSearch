Help & Support

Get help with FastMail Search and report technical issues.

Troubleshooting Basics

Before contacting support, please verify the following:

  • You are running Classic Microsoft Outlook (not the "New Outlook").
  • You have completely closed and restarted Outlook after running the installer.
  • You have verified that the add-in is enabled via File > Options > Add-ins > COM Add-ins.
  • You have reviewed our Frequently Asked Questions.

Generating Diagnostic Logs

If you are experiencing crashes, indexing failures, or unexpected UI behavior, please generate a diagnostics package.

  1. Open FastMail Search via the Outlook Ribbon.
  2. Click the Help & Diagnostics button.
  3. Click the Export Diagnostics Package button.
  4. Save the generated .zip file to your desktop.
The diagnostic package contains application logs and schema information but safely obfuscates or excludes sensitive email content. However, please review the `.log` files inside the zip if you have strict privacy concerns before sending them to us.

Contacting Us

Please email our support team and attach the generated Diagnostic .zip file (if applicable) alongside a detailed description of your problem.

  • Your Classic Outlook version and bitness (e.g., Office 365 64-bit).
  • A clear description of what you were doing when the issue occurred.
