Frequently Asked Questions

What is FastMail Search?

FastMail Search is a high-performance local full-text search add-in exclusively for Classic Microsoft Outlook. It rapidly indexes your emails in an embedded, fully private SQLite database without relying on external cloud services.

Which Outlook versions are supported?

FastMail Search supports Classic Microsoft Outlook for Windows (Office 365, 2019, 2016, and some earlier versions running on .NET Framework 4.8).

Does it work with 32-bit and 64-bit Outlook?

Yes. The architecture handles COM registration natively, ensuring the correct .NET environment loads automatically for both 32-bit and 64-bit Classic Outlook installations.

Is Outlook Classic required?

Yes. The add-in utilizes COM extensibility to integrate directly into the Outlook ribbon. The "New Outlook for Windows" (which is essentially a web wrapper) does not support classic COM Add-ins and is therefore not supported.

How do I install FastMail Search?

Close Classic Outlook, download the official installer, and run it. Please refer to our step-by-step Installation Guide.

Why does Windows show a SmartScreen warning?

The installer currently lacks an Authenticode Digital Signature. Microsoft flags all unsigned software. Please read the SmartScreen Warning Guide for safe validation steps.

How do I verify the installer?

You can verify the installer's integrity by comparing its SHA-256 hash using Windows PowerShell. The hash must match the signature listed on our Download page. See the Installation Guide for the exact command.

What should I do if the Outlook ribbon is missing?

Sometimes Outlook automatically disables add-ins if it detects slow performance during startup. Go to File > Options > Add-ins > COM Add-ins (Manage) > Go... and ensure the checkbox next to FastMail Search is ticked.

How does the 30-day trial work?

FastMail Search includes a fully functional 30-day free trial with unrestricted local email search and background indexing. No credit card or registration is required to start your trial.

How do I activate a license?

FastMail Search operates 100% offline without online telemetry or activation servers. To purchase an annual license, launch FastMail Search via the Outlook ribbon, copy your Hardware ID from the Activation dialog, and email your purchase request to our team at developer.diptesh@gmail.com. You will receive an offline RSA-signed license key. Enter this key into the Activation dialog to unlock the software.

What does FastMail Search cost?

FastMail Search is available for ₹499 for a 1-year license. The license includes 1 year of software usage and updates from the date of purchase. (License renewal policy is to be determined; no automatic renewal or recurring billing is implemented.)

Will uninstalling delete my indexed email database?

No. By default, running the uninstaller removes the binaries and Registry keys, but preserves your user data (FastMailSearch.db) and licensing info inside %USERPROFILE%\Documents\FastMailSearch. If you reinstall later, your index will be restored.

How can I contact support?

If you encounter bugs, crashes, or indexing failures, please visit the Support page for details on how to generate diagnostic logs and contact our team, or visit our GitHub Repository.
