# Security Policy

## Supported Versions

Security updates and patches are provided for the following version(s) of FastMail Search:

| Version | Supported |
| :--- | :--- |
| **v1.0.6+** | **Yes** |
| < v1.0.6 | No |

---

## Reporting a Vulnerability

The security and privacy of user data are paramount. FastMail Search operates entirely offline and does not transmit data or credentials to external servers. However, if you discover a security vulnerability or potential threat within the application, we appreciate your help in disclosing it responsibly.

### How to Report

Please report security issues privately via email:

- **Security Contact:** [developer.diptesh@gmail.com](mailto:developer.diptesh@gmail.com)

When reporting, please provide:
1. A description of the vulnerability, including severity and potential impact.
2. Step-by-step instructions or proof-of-concept demonstrating how to reproduce the issue.
3. Your operating system version, Microsoft Outlook build, and FastMail Search version.

### Responsible Disclosure Guidelines

- **Do NOT open a public issue** on GitHub for sensitive security vulnerabilities.
- Please allow reasonable time for the issue to be analyzed, verified, and remediated before disclosing any details publicly.
- While inquiries are addressed as promptly as feasible, no specific service level agreement (SLA) or guaranteed response window is implied.

Thank you for helping keep FastMail Search safe and secure.
