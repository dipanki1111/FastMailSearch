Installation Guide

Follow these steps to safely install and configure FastMail Search for Classic Microsoft Outlook.

1. Download the Installer

Download the official installer (FastMailSearch-v1.0.6-Store-Setup.exe) from the Download Section. Ensure you download the file only from the official source provided on this website.

2. Verify the Checksum (Optional but Recommended)

Before running the installer, verify the file's SHA-256 checksum to ensure it was not corrupted during download.

Open PowerShell and run the following command:

Get-FileHash -Algorithm SHA256 "C:\Path\To\Downloads\FastMailSearch-v1.0.6-Store-Setup.exe"

The resulting hash should exactly match: 7DD3E976A3C6F741B6AAA9876D4A236A85F93B85045AC7120839C91705BB25FA

3. Prepare Outlook

Crucial Step: FastMail Search cannot install safely if Classic Outlook is actively running.

  • Save any draft emails.
  • Close Classic Microsoft Outlook completely.

If you forget, the installer will gently remind you to save your work and close the application before proceeding.

4. Run the Installer

Double-click the downloaded FastMailSearch-v1.0.6-Store-Setup.exe file.

Note: You may see a "Windows protected your PC" warning. This is expected because the application is awaiting a final Authenticode code-signing certificate. Please read our SmartScreen Warning Guide for instructions on how to safely proceed.

The installer will extract the necessary files to your per-user application data folder and automatically register the COM add-in in the Windows Registry. No Administrator privileges (UAC) are required.

5. Launch Outlook & Verify

Open Classic Microsoft Outlook. Navigate to your Home ribbon.

You should see a new group containing the FastMail Search button. Clicking it will launch the search interface.

Troubleshooting a Missing Ribbon

If the button is missing:

  1. Go to File > Options > Add-ins.
  2. Look for "FastMail Search Classic Outlook Add-In" in the Active Application Add-ins list.
  3. If it is in the Inactive or Disabled list, select "COM Add-ins" from the Manage dropdown at the bottom and click Go...
  4. Check the box next to FastMail Search and click OK.

Upgrades & Uninstallation

Upgrading

To upgrade from a previous version, simply run the new installer. The setup process will automatically detect your existing installation and preserve your local search index (FastMailSearch.db).

Uninstalling

To remove the application, run the Uninstall-FastMailSearch.ps1 script provided in your installation directory, or use Windows Settings > Apps. Uninstallation removes the program files and Registry keys, but safely preserves your indexed email database and licensing data in %USERPROFILE%\Documents\FastMailSearch in case you decide to reinstall.
