Windows SmartScreen Warning Guide

Understanding why Windows may block the installer and how to proceed safely.

Why does Windows show "Windows protected your PC"?

When you attempt to run the FastMailSearch-v1.0.6-Store-Setup.exe installer, Windows Defender SmartScreen may display a blue warning screen.

This happens because our current v1.0.6 installer is an unsigned executable. Software distributed on Windows typically requires an expensive "Authenticode Code Signing Certificate" to prove the developer's identity to Microsoft. Because we are currently finalizing this certification process, the installer lacks this digital signature.

Note: Windows flags all unrecognized and unsigned executables downloaded from the internet by default, regardless of whether they are safe.

⚠️ Safety First: Do not imply that an unsigned installer is automatically certified as safe. We strongly advise that you proceed only if you have downloaded the installer from our official website and independently verified the file integrity.

How to verify the Installer

Before proceeding past the warning, confirm the file is exactly what we published:

  1. Right-click the downloaded FastMailSearch-v1.0.6-Store-Setup.exe file and select Properties.
  2. Check that the file size is approximately 4.09 MB (4,290,560 bytes).
  3. Go to the Digital Signatures tab (if present). You will notice it is currently blank or missing, which confirms it is unsigned.
  4. Generate the SHA-256 Checksum using PowerShell (see the Installation Guide for the command) and verify it exactly matches the official signature published on our Download Page.

How to proceed (Run anyway)

If you have verified the checksum and accept the risk of running an unsigned executable, you can bypass the warning to install the add-in:

  1. When the blue "Windows protected your PC" dialog appears, click the More info link text.
  2. The dialog will expand to show the app name (FastMailSearch-v1.0.6-Store-Setup.exe) and Publisher (Unknown publisher).
  3. Click the Run anyway button that appears at the bottom.

Note: Do NOT disable Microsoft Defender or SmartScreen globally in your Windows settings. These features are critical for your everyday security.

When will this be fixed?

We are in the process of acquiring a commercial Authenticode Code Signing Certificate. Once acquired, future updates will be digitally signed, and the Microsoft Store / Windows SmartScreen warnings will no longer appear.
